## 二、验证过的检查项

1. **单件试穿**：每件部件单独配素体渲染，检查对位、轮廓、内容是否符合规格
2. **头饰组合**：6 种发型 × 草帽、兔耳发箍，检查发饰与发型是否冲突（历史问题：头饰差分残留发块盖住发型）
3. **长发与衣服**：黑长直/金大波浪 × 毛衣、连衣裙，检查长发与衣物遮挡关系
4. **随机全套**：12 组随机搭配压力测试

## 三、已知设计妥协（不是 bug）

1. **露肩装露出白色肩带**：dress_02 吊带、dress_06 抹胸的肩膀处会露出素体自带的白 T 肩带。原因是素体穿白 T，露肩部件盖不住。视觉上像内搭，一般可接受。
   - 若不能接受：需重出素体（改成无袖打底衫），但已生成的部件图都基于旧素体参考，会有细微体型差异，代价大，不建议。
2. **dress_04 背带裙内搭白 T 露出**：规格本来就写的「不含内搭衫」，配素体白 T 正好。
3. **bottom_03 / bottom_05 裤长到小腿下段**：规格写「到脚踝」，出图略短，视觉无碍。

## 五、素材更新流程

重出的图放回 `assets/` 对应品类目录，**文件名不变（同名覆盖）**，然后依次运行：

```bash
python3 tools/process_assets.py   # 去水印→绿幕抠图→裁切→差分→对齐
python3 tools/to_webp.py          # 转 webp（游戏加载用）
python3 tools/make_thumbs.py      # 生成分类面板缩略图
```

刷新浏览器即可看到效果。
