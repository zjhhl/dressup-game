> 更新：2026-10-18。基于全部 26 张素材逐张试穿检查的结果。
> 重出的图放回 `assets/` 对应品类目录，**文件名不变（同名覆盖）**，然后重跑 `python3 tools/process_assets.py` 即可，游戏自动生效。

## 一、必须重出（4 张）

### 1. hair_02 黑色长直发

- **位置**：`assets/hair/hair_02.png`
- **问题**：黑长发画窄了，素体原本的栗棕色短发从黑发内侧、耳后、发梢处大面积露出，看起来像叠了两层发型
- **重出 prompt（在原模板基础上追加）**：

```
只有发型：黑色长直发及腰，空气刘海。
与参考图素体完全相同的角色、相同的脸、相同的正面站姿，
新发型完全包裹住素体原有头发，任何角度都看不到素体原本的栗棕色头发，
发量饱满贴合头型，发丝轮廓略宽于素体头部轮廓，
{风格后缀全文}
```

### 2. hair_06 金色大波浪长卷发

- **位置**：`assets/hair/hair_06.png`
- **问题**：同 hair_02，金发内侧露出素体棕发条（左右肩前各一条）
- **重出 prompt**：同 hair_02 的追加句，发型描述换成「金色大波浪长卷发，中分」

### 3. top_05 皮夹克

- **位置**：`assets/top/top_05.png`
- **问题**：黑色面料高光强烈，与绿幕过渡带、发色剔除处理三方冲突，处理后肩部/拉链旁出现成片白斑，脚本无法修复
- **处理方式**：换成深蓝/哑光材质绕开（黑色高反光面料对所有 AI 抠图流水线都是坑）
- **重出 prompt**：

```
只有一件上衣：哑光深蓝色牛仔夹克，银色拉链，长袖。
与参考图素体完全相同的角色、相同的体型、相同的正面站姿，
上衣穿在素体身上贴合身体，面料哑光无反光无高光，
衣服轮廓不超过素体手臂和躯干轮廓范围，
{风格后缀全文}
```

### 4. shoes_03 棕色圆头小皮靴

- **位置**：`assets/shoes/shoes_03.png`
- **问题**：靴筒窄且低于脚踝，素体光脚从靴口露出，视觉像没穿上
- **重出 prompt**：

```
只有一双鞋：棕色圆头小皮靴，到脚踝上方。
与参考图素体完全相同的角色、相同的正面站姿、两脚并拢，
靴筒包住整个脚部，靴口高于脚踝位置，完全遮住素体双脚，不露出任何皮肤，
靴筒略宽于素体小腿，脚部位置与参考图完全一致，鞋底贴地，
{风格后缀全文}
```

## 四、已知设计妥协（不是 bug，别当问题报）

1. **露肩装会露出白色肩带**：dress_02 吊带、dress_06 抹胸的肩膀处会露出素体自带的白 T 肩带。原因是素体穿白 T，露肩部件盖不住它。视觉上像内搭，一般可接受。
   - 若不能接受：需重出素体（改成无袖打底衫），但已生成的部件图都基于旧素体参考，会有细微体型差异，代价大，不建议。
2. **dress_04 背带裙内搭白 T 露出**：规格本来就写的「不含内搭衫」，配素体白 T 正好，属正确效果。

## 五、重出后的操作流程

1. 新图覆盖 `assets/` 对应目录同名文件
2. 跑批处理：`python3 tools/process_assets.py`
3. 刷新浏览器（`index.html`）即可看到效果
4. 不确定效果时让我合成验证图检查一遍
