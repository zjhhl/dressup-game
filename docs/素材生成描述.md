# 换装游戏素材生成描述文档（Q版三头身）

> 用法：每条 prompt 独立出一张图。生成顺序：先素体，锁死素体图后，其余全部以素体为参考图（图生图 / 多图参考）。
> 素体图是全局一致性锚点，一旦确定绝不重生成。

---

## 一、全局规则（每个工具里都要设置）

| 项 | 值 |
|---|---|
| 画布比例 | 2:3，建议 1000×1500 |
| 背景 | 纯绿幕 #00FF00（后期抠透明） |
| 姿势 | 正面站立，双手自然下垂贴身体两侧，两脚并拢 |
| 角色位置 | 居中，头顶到脚底占满画面高度约 90% |
| 参考图 | 除素体外，全部挂素体图做参考 |

**每条 prompt 末尾统一拼接的风格后缀（原样复制，不改一字）：**

```
Q版二次元三头身少女，头大身小比例约1:2，圆润简洁线条，柔和赛璐璐平涂上色，
色块干净无噪点无厚涂笔触，纯绿色背景#00FF00，全身正面站立，
双手自然下垂贴身体两侧，两脚并拢，角色居中占满画面，
无投影无阴影，无文字无水印，游戏换装素材
```

**负面提示词（工具支持就填）：**

```
写实, 厚涂, 多人, 侧面, 背面, 仰视, 俯视, 投影, 阴影, 复杂背景, 文字, 水印, 边框
```

**验收标准：**
- [ ] 三头身比例正确（头宽 ≈ 身宽）
- [ ] 手臂自然下垂不叉腰不抬手
- [ ] 五官清晰，脸占头部大部分
- [ ] 绿幕纯净无杂色

素体确认后：**固定 seed / 固定这张图做所有后续参考图**。

## 九、出图后处理清单（每张都要过）

1. **抠图**：绿幕 → 透明 PNG，检查发丝/裙摆边缘无绿边（绿边用去边工具处理）
2. **统一尺寸**：全部缩放回与素体完全相同的画布尺寸和角色位置（以素体图为底对齐，不要目测）
3. **裁切**：发型/上衣等部件图可裁到有效区域，但**同品类裁切规则必须一致**（游戏里按同锚点摆放）
4. **压缩**：tinypng 类工具压一遍（主包 4MB 限制）
5. **命名**：按上文文件名，`品类_编号.png`，归档到 `res/hair/`、`res/top/` 等目录

## 十、图层 z 序（引擎里的叠放顺序，从小到大）

```
shoes(5) → bottom(15) → 素体身体(10，随发型归入hair层之下) → top(20) / dress(20) → hair(10) → acc(30)
```

穿 dress 时隐藏 top + bottom（配置表 `hide` 字段处理）。
