# 换装小屋

Q 版三头身纸片人换装小游戏，纯静态网页，零依赖，打开即玩。

## 在线玩

https://zjhhl.github.io/dressup-game/

## 玩法

- 左侧是角色，右侧分类切换：发型 / 鞋子 / 上衣 / 下装 / 连衣裙 / 饰品
- 点缩略图即换，每个分类都有「脱掉」
- 穿连衣裙会自动隐藏上衣和下装
- 「随机穿搭」一键配一套，配合「重置」重来

## 本地运行

```bash
# 任意静态服务器，例如
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

直接双击 `index.html` 也能玩（file:// 协议下无法用 canvas 导出图片，其余功能正常）。

## 目录结构

```
index.html                  游戏本体（单文件，零依赖）
res/                        游戏素材（透明 webp，按品类分目录）
docs/素材生成描述.md          AI 生图 prompt 全文档（素体+26 件部件）
docs/素材重出清单.md          素材问题清单与重出指引
tools/process_assets.py      素材批处理：去水印→绿幕抠图→裁切→差分→对齐
tools/to_webp.py             PNG 批量转 webp
```

## 素材流水线

素材由 AI 生图工具产出（绿幕背景 1024×1536），经 `tools/process_assets.py` 处理成游戏用透明图层：

1. 去右下角生成工具水印
2. 绿幕抠透明（含去绿边）
3. 按品类裁切/差分（生成图都是全身像，需要裁掉会盖住其他图层的部分）
4. 与素体肤色区域互相关自动对齐（每张生成图体型位置有漂移）

图层顺序（z 从小到大）：素体 10 → 发型 11 → 鞋 12 → 上衣 13 → 下装 14 → 连衣裙 15 → 饰品 20。

## 素材重出流程

原始绿幕图放在本地 `assets/`（未入库）。重出的图同名覆盖后：

```bash
python3 tools/process_assets.py   # 重新处理
python3 tools/to_webp.py          # 转 webp
```

细节见 `docs/素材重出清单.md`。
